# Glyma semantic icon manifest.
#
# Single source of truth for the icon system. Each line maps a semantic icon
# name used by the application to a real SVG asset in resources/icons/.
#
#   <semantic-name> = <hugeicons-filename>
#
# Rules:
#   * Blank lines and lines starting with '#' are ignored.
#   * The asset filename must exist in resources/icons/ (verified at configure
#     time; a missing file is a hard CMake error).
#   * Names are stable identifiers: widgets never reference filenames directly.
#   * To add an icon: pick an asset from resources/icons/, add one line here,
#     then use IconManager::icon("<semantic-name>"). No other file changes are
#     required; CMake regenerates the Qt resource file from this manifest.
#
# Style: Hugeicons "stroke-rounded" free set (@hugeicons/core-free-icons, MIT).
# All assets use a single 24x24 viewBox with a monochrome stroke; Glyma tints
# them at runtime to match the active theme.
